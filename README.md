# FIND EXTRA MONEY — 30 дней поиска дополнительного заработка

Небольшой адаптивный сайт на HTML, CSS и JavaScript. Помогает пройти 30-дневный план поиска дополнительного дохода и отмечать выполненные задания.

## Возможности

- План из 30 ежедневных заданий.
- Разделение на четыре этапа.
- Общий и недельный индикаторы прогресса.
- Сохранение отметок в браузере через `localStorage`.
- Сброс прогресса.
- Адаптация для мобильных экранов.

## Как запустить локально

1. Скачайте или клонируйте репозиторий.
2. Откройте `index.html` в браузере.

Сборка и установка зависимостей не нужны.

## Как опубликовать через GitHub Pages

1. Создайте новый публичный репозиторий на GitHub, например `find-extra-money`.
2. Загрузите в корень репозитория файлы `index.html`, `styles.css`, `script.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через некоторое время GitHub покажет ссылку на опубликованный сайт в разделе Pages.

Прогресс хранится в локальном хранилище браузера на конкретном устройстве. Он не синхронизируется между разными браузерами или устройствами.
